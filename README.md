# 浙江农林大学本科毕业论文排版skill

**论文写完了，别再被格式困住。**

字号不统一、标题层级混乱、图表格式难调整……毕业论文最后的排版，往往比想象中更费时间。

这个项目希望帮你省下这些重复劳动：把已有的论文交给 AI 助手，辅助整理格式，生成新的排版文件，并告诉你还有哪些地方需要留意。目前默认适配浙江农林大学（ZAFU）本科毕业论文规则；其他学校需要提供并核对相应规则，不能直接套用默认配置。

✨ **Word / LaTeX 双路径排版，支持两种格式输出。**
📂 **原稿保留，结果另存，不把文件越改越乱。**
📝 **专注排版，不让 AI 擅自润色、补写或重写论文。**

> 目前为预览版，欢迎试用和反馈。这是独立社区项目，不是学校官方工具；交稿仍以所在学院当年的要求为准。

## 🙋 适合谁使用？

- **论文已经写完，正在准备交稿的同学**：希望减少逐段调整字体、标题和图表的时间。
- **从多个文件拼成论文的同学**：不同章节格式不一致，想统一整理。
- **习惯用文字稿写作的同学**：希望把 Markdown 或 TXT 稿件整理成 Word，或使用 LaTeX 排版。
- **想保留不同交付版本的同学**：从同一份文字稿分别生成 Word 和 LaTeX 版本。

## ✨ 能帮你做什么？

### 📄 Word 论文排版

按学校规范整理整篇论文，从章节结构到段落细节统一设置：

- **标题与章节**：统一一、二、三级标题的字体、字号、加粗、对齐和编号，设置大纲层级及标题与下文的分页衔接。
- **正文与段落**：统一中西文字体、字号、行间距、段前段后间距、首行缩进和对齐方式，保留正文中的强调与上下标。
- **页面与页码**：设置 A4 纸张、页边距、页眉页脚位置，补齐正文和摘要页眉，安排前置部分的罗马页码与正文的阿拉伯页码。
- **封面、摘要与目录**：原样插入学校模板封面和诚信页，整理中英文题目、摘要及关键词，建立目录域并核对标题层级与页码。
- **图片与表格**：调整图片尺寸与居中，统一图题、表题和编号，设置三线表、跨页重复表头及表格分页。
- **公式排版**：支持行内公式与独立公式，将常用 LaTeX 数学写法转换为 Word 原生公式，设置公式居中、编号右对齐及公式段落间距。
- **交叉引用**：为图表题注建立书签，将正文中的图表引用关联到对应题注，生成可在 Word 中更新的交叉引用域。
- **参考文献**：统一文献标题、条目字体、字号、缩进和行距，检查条目编号与正文数字引用的对应关系；默认 ZAFU 配置采用宋体五号，西文字体可指定为 Times New Roman。

### 📐 LaTeX 论文排版

将 Markdown 或 TXT 稿件生成可继续编辑的 LaTeX 工程，并编译为 PDF。支持章节、双语摘要、关键词、图片、表格及数学公式；结合 `.bib` 文件和 `[@key]` 引用，可生成 GB/T 7714-2015 著者—年份格式的引文与参考文献。同一份文字稿也可同时输出 Word 和 LaTeX 两种版本。

### 🔍 页面预览与排版检查

生成整篇论文的 PDF、页面总览和高清预览，由 AI 助手逐项检查目录、分页、页眉页码、图表位置、公式及参考文献。结合图文位置分析，定位标题落在页尾、图题位置异常、目录尾页过疏等问题，修复后重新检查页面。排版前后提供缺项清单，方便核对论文各部分是否齐全。

### 📁 成品与版本管理

每次排版独立保存，原稿完整保留。Word、PDF、LaTeX 工程及检查说明分目录整理，成品路径清晰，方便直接取用、比较版本和继续修改。

## 🚀 怎么开始？

这是一个 **Skill**，可以理解为给 AI 助手使用的一套论文排版工具，**不是上传文件就能在线转换的网站**。

你需要一个能够读取电脑文件、执行本地工具的 AI 助手。下载或安装本项目后，让助手读取项目里的使用说明；首次使用可能需要配置运行环境，可以让助手引导完成。

然后，告诉它论文在哪、你想要什么结果。例如：

```text
请读取这个项目的 SKILL.md，帮我排版这份毕业论文。
文件在 D:\毕业论文\我的论文.docx。

按浙江农林大学的规则整理，输出 Word 文件。
不要润色、补写或重写论文，也不要覆盖我的原稿。
原样补齐缺失的模板封面和诚信页，禁止修改或填写模板内容。
补齐缺失页眉，实际检查排版后的页面；如果需要整篇重建，请先说明原因。
完成后告诉我结果保存在哪里，还有哪些地方需要检查。
```

💡 平时使用 Word 的同学，直接提供 `.docx` 文件即可，不必为了排版先学习 LaTeX。

具体运行方法供 AI 助手或需要手动操作的用户查阅：[使用说明](SKILL.md)。

### 本地环境与命令

需要 **Python 3.11 或更高版本**，**不用安装 uv**。首次使用需安装项目依赖，可以让 AI 助手引导完成。在仓库根目录执行：

```powershell
python -m pip install -r requirements.txt
python scripts/thesis_format.py --help
python scripts/thesis_format.py "D:/毕业论文/论文.docx"
python scripts/thesis_format.py "D:/毕业论文/论文.docx" --quality fast
python scripts/thesis_format.py "D:/毕业论文/论文.docx" --render-backend word
python scripts/thesis_format.py "D:/毕业论文/论文.md" --backend latex
python scripts/thesis_format.py "D:/毕业论文/论文.md" --backend both
```

这些命令是脚本入口。已有 DOCX 的默认规范化路径不会插入封面；缺少前置页时，助手需按 [SKILL.md 的前置页补齐步骤](SKILL.md#前置页补齐) 先列出缺项，再使用模板组合路径补齐，不能把默认命令的输出直接当成完整成品。

已安装过依赖的环境可以直接运行，不必每次重新安装。如果电脑上有多个 Python 环境，请让助手确认使用的是已安装项目依赖的那个环境。普通 Python 安装方式与 uv 开发方式都受支持。

按所需功能配置额外工具：

| 功能 | 额外条件 |
|---|---|
| Word 结构检查、DOCX 修复或生成 | 不需要启动 Word，也不需要 TeX 编译器 |
| Word 导出 PDF、更新目录与分页核验 | 可用的 Microsoft Word（Windows）或 LibreOffice 转换环境；以实际报告为准 |
| LaTeX 编译 PDF | PATH 上的 XeLaTeX 或 Tectonic，以及模板所需字体和宏包 |
| 页面预览 | 对应的 PDF 工具，如 Poppler；Final 默认请求，Fast 可跳过 |

首次 ZAFU LaTeX 构建需联网取得固定版本模板；Tectonic 也可能下载编译资源。学校适配优先使用宋体、黑体、楷体、仿宋与 Times New Roman，缺失字体或宏包需依据编译报告处理。工具不自动安装大型 TeX 环境或修改系统 PATH。只需要工程时使用 `--no-compile`；无编译器时也会明确报告仅交付源码，而非已生成 PDF。

常用选项：`--quality final|fast` 选择正式交付或快速草稿；`--render-backend word` 指定目标 Word 引擎；`--conservative` 要求保守处理；`--latin-font "Times New Roman"` 指定 Word 西文字体。旧 `--check structural|layout|visual` 仍可显式覆盖检查范围，`--mode` 的专家语义保留。实际视觉审阅需要助手打开图片并记录证据。

内部自动选择文字源直接构建、普通 Word 批量规范化或复杂区域保守保留路线。模板按内容哈希缓存，同次执行共享解析结果；原稿、正文强调及重要资产得到保护。学校 AI 使用披露是独立要求，工具不伪造声明。实现与限制见 [排版架构](references/formatting_first_architecture.md)、[视觉验收](references/optional_visual_review.md) 和 [性能与回归](references/performance_baseline.md)。

## 📚 Word 和 LaTeX，怎么选？

| 你的情况 | 建议选择 |
|---|---|
| 已经用 Word 写好论文 | 继续使用 Word，整理后生成一个新文件 |
| 用 Markdown 或 TXT 写作，最终需要 Word | 提供文字稿，生成 Word 文件 |
| 想用 LaTeX 排版 | 提供 Markdown 或 TXT 稿件，生成可继续编辑的 LaTeX 工程；环境就绪后生成 PDF |
| 想同时保留两种版本 | 提供 Markdown 或 TXT 稿件，分别生成 Word 和 LaTeX 版本 |

两种排版方式的分页和外观可能不同。目前不提供任意 Word 文件直接无损转换为 LaTeX 的功能。

LaTeX 学校适配目前为草稿级，不代表学校格式认证。本排版工作流的封面和诚信页必须从明确的学校原页原样插入，禁止填写、改写或通过宏重画；可通过显式元数据插入已确认的前置页 PDF。配置见 [LaTeX 学校适配说明](references/zafu_latex_adapter.md)。

## 📍 排版后的文件在哪里？

默认保存在原论文旁边的 **`thesis-output` 文件夹**中，每次排版都有独立的结果目录。

- **`deliverables`**：排版成品，拿结果时看这里。
- **`reports`**：检查说明，查看还有什么问题需要处理。
- **`work`**：过程文件，普通使用时不用关心。

也可以直接告诉 AI 助手：“请把排版结果保存到我指定的文件夹，并告诉我最终文件路径。”

## 💬 几个你可能关心的问题

**会改我的论文内容吗？**

不做 AI 润色、补写或重写。排版过程中会进行摘要局部整理、标题编号、图表引用等格式处理。缺失的模板前置页原样补齐，封面和诚信页禁止填写或修改；整篇重建等超出已有要求的操作需要明确授权。

**格式很乱的 Word 也能用吗？**

可以尝试，但不能保证所有内容都识别准确。越复杂的稿件，越需要检查结果；识别有误时，可以告诉助手哪个位置应当是正文、标题或题注，再进行纠正。

**能直接拿去交稿吗？**

助手应先核对模板封面是否原样保留、目录是否更新、实际分页和版式是否符合要求，再交付论文并列出剩余问题。模板封面的空白字段不作为缺项，也不填写。交稿仍需遵循所在学院的具体要求，排版结果不代表学校的格式审查结论。

**页眉会写什么？**

Word 默认使用“浙江农林大学本科生毕业论文（设计）”。已有 DOCX 和从 Markdown/TXT 新建的文档，均为可识别正文/摘要节创建缺失页眉、补齐空页眉，并核对首页及奇偶页变体。独立目录节使用空页眉，封面和诚信页保持模板原样；共享页眉要隔离，避免连带修改封面。复杂分节无法可靠处理时，列出未补齐的位置并继续定向检查。用户可明确指定论文题目页眉，或用 `--header-mode preserve` 保留原页眉。LaTeX 按其模板处理。

## 🧰 项目结构与提交范围

- `SKILL.md`、`agents/`：AI 助手的入口说明与展示信息。
- `scripts/`：统一入口、公共语义处理、Word 与 LaTeX 后端。
- `profiles/`、`references/`：学校规则和按需读取的技术说明。
- `assets/`：有意保留的模板与本项目的 LaTeX 适配文件。
- `tests/`：测试代码与固定样例，不是用户论文的存放位置。

仓库保留源码、规则、锁文件及必要的模板/测试资源；不提交个人论文、排版成品、虚拟环境、缓存或外部模板下载目录。`.gitignore` 按生成目录忽略成品，不全局屏蔽 DOCX/PDF 等可能属于有效资源的格式。自定义输出到其他目录时，需自行补充忽略规则并检查 `git status`。

本地检查入口（不修改测试期望）：

开发者可继续使用 uv 管理锁定环境；这不会增加普通用户的安装要求。下面是可选的开发检查命令：

```powershell
uv run --no-sync python scripts/verify_skill_health.py
uv run --no-sync python -m unittest discover -s tests -p "test_*.py"
git diff --check
```

健康检查仅核对配置与入口，测试通过也不替代实际页面核验。不要将含姓名、学号、批注、未公开研究内容的文件作为公开测试样例。
