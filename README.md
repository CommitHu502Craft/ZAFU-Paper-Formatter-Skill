把 `.docx`、Markdown 或 TXT 交给本地 AI 助手，按浙江农林大学（ZAFU）本科毕业论文规范整理成 Word、PDF 或 LaTeX 工程。标题层级、字体字号、页眉页码、目录、图表题注、公式和参考文献一次统一；原稿不动，结果另存。

## 30 秒了解

| 你手上有什么 | 可以得到什么 |
|---|---|
| 已经排过版、但格式不统一的 Word 论文 | 按学校规范整理后的 Word，可另存 PDF |
| 只有正文、没有封面和目录的 Word | 原样补齐模板封面、诚信页和目录域 |
| Markdown / TXT 文字稿 | 新建 Word，或生成可编译的 LaTeX 工程 |
| 想同时保留两种交付 | 同一份文字稿分别生成 Word 和 LaTeX |

排版只处理格式：**不润色、不补写、不重写内容，也不覆盖原稿。**

## 为什么值得用

毕业论文最后阶段的排版，通常是这些事：

- 一级、二级、三级标题的字体字号各不相同，编号对不上；
- 正文中西文字体混乱，行距、段前段后、首行缩进逐段调；
- 封面、诚信页、目录、摘要、正文的页码规则不同；
- 图题、表题、三线表、公式编号、交叉引用分散在全文；
- 参考文献的字体、缩进、编号和正文引用对不上。

这个项目把这些规则固化成可检查的流程：先识别文档结构，再统一格式，最后渲染成页面逐项核对。你只需要告诉助手论文在哪里、按哪所学校的要求处理。

## 能做什么

### 📄 Word 排版

- **标题与章节**
  - 统一各级标题的字体、字号、加粗、对齐与编号，设置大纲层级。
  - 章节标题另起一页；“引言/前言/绪论”作为无编号一级标题进入目录，正文页码从该页起算。
- **正文与段落**
  - 统一中西文字体、字号、行距（ZAFU 默认固定 20 磅）、段前段后和首行缩进。
  - 保留正文中的加粗、斜体和上下标。
- **页面与页码**
  - 设置 A4 纸张、页边距、页眉页脚位置。
  - 封面/诚信页沿用模板页码，目录与摘要用罗马数字，正文从 1 开始。
- **前置页**
  - 原样插入学校模板封面和诚信承诺书，**不填写、不改写**模板字段。
  - 整理中英文题目、摘要和关键词。
  - 建立真实目录域，Word 打开时自动刷新页码。
- **图片与表格**
  - 超出版心的图片等比缩小并居中。
  - 统一图题、表题；三线表、表头跨页重复、表格内文字居中。
- **公式**
  - 行内与独立公式转换为 Word 原生公式（OMML）。
  - 公式居中，编号随公式保留。
- **交叉引用**
  - 为图表题注建立书签。
  - 把正文中的“图 1 / 表 1”引用替换为可更新的 Word 域。
- **参考文献**
  - 统一标题、条目字体字号、缩进和行距。
  - 中文宋体、西文 Times New Roman 五号。
  - 检查编号连续性与正文引用对应关系。

### 📐 LaTeX 排版

- 从 Markdown / TXT 生成可继续编辑的 LaTeX 工程，并编译为 PDF。
- 支持章节、双语摘要、关键词、图片、表格和数学公式。
- 配合 `.bib` 文件与 `[@key]` 引用，生成 GB/T 7714-2015 著者—年份格式的引文与参考文献。
- 使用固定版本的 ZAFU 外部文档类，首次构建需联网获取模板。

### 🔍 版面检查与预览

- 生成全文 PDF、总览缩略图和重点页高清图。
- 逐项核对目录、分页、页眉页码、图表位置、公式和参考文献。
- 输出排版前后的缺项清单，方便确认论文各部分是否齐全。
- 发现问题后修改并重新渲染受影响的页面，而不是只看“检查通过”。

### 📁 成品与版本

- 每次排版独立保存，原稿完整保留。
- Word、PDF、LaTeX 工程和检查报告分目录存放。
- 成品路径清晰，方便取用、比较版本和继续修改。

## 快速开始

### 方式一：让 AI 助手来做（推荐）

1. 下载或克隆本仓库；
2. 在能读取本地文件的 AI 助手中打开本项目，让它读取 `SKILL.md`；
3. 告诉它论文路径和目标。

可以直接复制这段：

```text
请读取这个项目的 SKILL.md，帮我排版毕业论文。
文件：D:\毕业论文\我的论文.docx

要求：
- 按浙江农林大学本科毕业论文规范排版，输出 Word 和 PDF；
- 不润色、不补写、不重写内容，不覆盖原稿；
- 缺封面/诚信页时原样补齐模板页，不要填写模板字段；
- 补页眉、页码和目录，并实际检查渲染后的页面；
- 完成后告诉我成品路径，以及还需要我核对的地方。
```

平时用 Word 的同学直接给 `.docx` 即可；不需要为了排版先学 LaTeX。

### 方式二：命令行

需要 Python 3.11+，不必安装 uv。首次使用安装依赖：

```powershell
python -m pip install -r requirements.txt
```

常用命令（在仓库根目录执行，把 `论文.docx` / `论文.md` 换成实际路径）：

- **常规整理**（已有封面/诚信页）
  `python scripts/thesis_format.py 论文.docx`
- **补齐模板前置页**（缺封面/诚信页）
  `python scripts/thesis_format.py 论文.docx --allow-structural-rebuild --mode conservative-repair`
- **快速草稿**（跳过渲染检查）
  `python scripts/thesis_format.py 论文.docx --quality fast`
- **Markdown / TXT → Word**
  `python scripts/thesis_format.py 论文.md`
- **Markdown / TXT → LaTeX**
  `python scripts/thesis_format.py 论文.md --backend latex`
- **同时生成 Word 和 LaTeX**
  `python scripts/thesis_format.py 论文.md --backend both`

默认命令只做规范化，不会凭空补前置页；原稿已有封面时用它。缺前置页时用第二条命令，模板页会原样插入，正文和资产仍按保守策略保留。

完整参数见 `python scripts/thesis_format.py --help`，行为细节见 [SKILL.md](SKILL.md)。

## 输出在哪里

默认在论文旁边生成 `thesis-output`：

```text
thesis-output/<论文名>/<运行ID>/
├── deliverables/    # 最终 Word / PDF，取这里
├── reports/         # 检查报告（summary.html 可直接打开）
└── work/            # 中间文件与渲染图，一般不用管
```

每次运行都有独立目录，不会覆盖上一次结果。也可以让助手把结果保存到指定文件夹。

## 边界：它不做什么

- **不润色、不补写、不重写**论文内容；只做格式、结构和引用层面的处理。
- **不覆盖原稿**，不把个人信息写进模板封面，不伪造签名或声明。
- **不替代学院审查**：最终以所在学院当年的正式要求和指导教师意见为准。
- **不保证复杂稿件 100% 识别**：扫描版、文本框、复杂分栏、旧式公式等可能保留原样并提示人工核对。
- **不做 DOCX → LaTeX 的无损转换**：LaTeX 路线只接受 Markdown / TXT。
- **LaTeX 学校适配为草稿级**：复用外部文档类，不宣称等同于学校格式认证。

## 交稿前检查清单

排版完成后，建议按这份清单过一遍：

- [ ] 封面、诚信页为学校模板原样，个人信息已按学院要求填写；
- [ ] 目录页码与正文一致（在 Word 中打开后会自动更新，也可全选后按 F9）；
- [ ] 中英文题目、摘要、关键词齐全；
- [ ] 页眉文字正确，封面/诚信页/目录页没有多余页眉；
- [ ] 页码连续：目录和摘要为罗马数字，正文从 1 开始；
- [ ] 每章另起一页，标题没有孤零零落在页尾；
- [ ] 图题在图下、表题在表上，图表编号连续，跨页表格有重复表头；
- [ ] 公式编号连续，行内变量没有丢字；
- [ ] 参考文献格式统一，正文引用能对应到条目；
- [ ] 与学院当年模板和导师意见再核对一次。

## Word 还是 LaTeX？

| 你的情况 | 建议 |
|---|---|
| 已经用 Word 写好论文 | 继续用 Word，整理后生成新文件 |
| 用 Markdown / TXT 写作，最终交 Word | 提供文字稿，直接生成 Word |
| 想用 LaTeX 排版 | 提供 Markdown / TXT，生成 LaTeX 工程后编译 |
| 想保留两种版本 | 提供 Markdown / TXT，`--backend both` |

两种路线的分页和外观可能不同，按学院要求选择即可。

## 环境与依赖

| 能力 | 需要 |
|---|---|
| Word 结构解析、格式修复、生成 DOCX | 无需安装 Word，也无需 TeX |
| DOCX → PDF、目录刷新、分页核验 | Windows 上的 Microsoft Word，或 LibreOffice |
| LaTeX 编译 PDF | PATH 上的 XeLaTeX 或 Tectonic，以及所需字体和宏包 |
| 页面预览（总览/高清页 PNG） | `pdftoppm`（Poppler）等 PDF 栅格化工具 |

中文字体优先使用宋体、黑体、楷体、仿宋和 Times New Roman；缺失字体或宏包时按编译/渲染报告处理。工具不会自动安装大型 TeX 环境，也不会修改系统 PATH。只需要 LaTeX 源码时加 `--no-compile`。

## 常见问题

**会改我的论文内容吗？**

不会润色、补写或重写。排版会做摘要标签合并、标题层级、编号、页眉页码、图表题注和交叉引用等格式处理；封面和诚信页保持模板原样，不填写任何字段。

**格式很乱的 Word 能用吗？**

可以，越复杂的稿件越需要复核。识别有误时可以告诉助手“这一段是正文/二级标题/图题”，用语义覆盖纠正，而不是直接改文字。

**目录页码为什么打开 Word 后才对？**

目录是真实的 Word 域，生成时写入的是缓存结果；文档设置了“打开时更新域”，Word 打开后会按最终分页刷新。PDF 预览反映的是刷新后的结果，其他不更新域的查看器可能显示旧页码。

**封面上的姓名、学号为什么不自动填？**

模板封面和诚信页属于受保护区域，工具只原样插入，不猜测、不填写个人信息；请在打印前自行填写或按学院要求处理。

**能直接拿去交稿吗？**

排版结果需要你按上面的清单核对后再提交；它不能替代学院的形式审查，也不构成“保证通过”的承诺。

## 项目结构

```text
SKILL.md              # AI 助手入口与工作流说明
agents/               # 助手展示信息
scripts/              # 统一入口、语义处理、Word / LaTeX 后端
profiles/             # 学校配置（默认 zafu_2022）
references/           # 规则、架构与验收说明
assets/               # 模板与 LaTeX 适配文件
tests/                # 单元测试与固定样例（不要放个人论文）
```

仓库只提交源码、规则、锁文件和必要的模板/测试资源；不提交个人论文、排版成品、虚拟环境或缓存。
