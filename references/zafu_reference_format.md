# Word 参考文献格式说明

采用用户提供的 GB/T 7714-2015 **著者—年份制**要求，不采用正文顺序编码制。

## 版式与处理边界

- 文后参考文献条目：按用户本次要求，中文和西文均设置为宋体五号（10.5 pt），首行不继承正文缩进。标题仍使用学校参考文献标题样式。LaTeX 的字体由其独立 CLS 决定，不受这条 Word 设置覆盖。
- 如果本次明确要求西文统一 Times New Roman，使用 `--latin-font "Times New Roman"` 覆盖西文字体；中文宋体与10.5 pt字号不变。不要把一次用户覆盖反写成所有学校模板的默认规则。
- Word 只统一版式并生成 `reports/reference-format.json` 的非破坏性检查提示。
- 不管理引用域、不自动关联/改写正文引用、不自动排序文献、不生成 a/b 对应关系、不改作者名、不猜补年份/页码/DOI。
- 根据既有无编号规则去除文后列表数字标签属于版式规范；不会把正文 `[1]` 猜改为某位作者。
- 中文拼音排序、外文名解析、条目真实性和缺失字段须人工核实；检查提示不是合规认证。

## 文后书写格式

| 类型 | 书写模板 |
|---|---|
| 期刊 | 作者. 题名[J]. 期刊名称，出版年，卷号(期号)：起止页码. |
| 书籍 | 著者. 书名[M]. 编者/译者. 版次（第1版省略）. 出版地：出版者，出版年：起止页码. |
| 论文集 | 著者. 论文集名[C]. 出版地：出版者，出版年：起止页码. |
| 学位论文 | 作者. 题名[D]. 保存地：保存单位，年份. |
| 专利 | 专利所有者. 专利题名：专利号[P]. 发布日期. |
| 标准 | 标准代号，标准名称[S]. 出版地：出版者，出版年月. |
| 电子文献 | 作者. 题名[文献类型/载体类型]. 出版或可获得地址，发表/更新日期或引用日期（按提供的要求选用）. |

没有的数据不补造；不同文献类型需要核对对应字段，不能用一种模板机械改写全部条目。

## 作者及排序

- 先中文，后外文。
- 中文按第1作者姓氏汉语拼音排序；外文按第1作者姓氏字母排序。
- 作者不超过3位时全部列出；超过3位只列前3位，随后加“等”或“et al.”。
- 外文姓全拼大写置前，名用大写首字母缩写；字母之间、姓与名之间用空格，缩写名后不加点，作者之间用逗号。
- 用户提供的个别末尾例子使用了混合大小写姓氏；检查按其明确文字要求“姓全拼大写”提示，但不自动改写原文。

```text
陈守常，曾大鹏. 油茶病害及其防治[M]. 北京：中国林业出版社，1989.
舒兰. 帽儿山天然次生林空间结构与更新计数模型[D]. 哈尔滨：东北林业大学，2019.
袁嗣令，张能唐，翁月霞，等. 油茶炭疽病的研究[J]. 植物保护学报，1963，2(3)：253-261.
REICH P B, TJOELKER M G, MACHADO J, et al. Universal scaling of respiratory metabolism, size and nitrogen in plants[J]. Nature, 2006, 439(7075): 457-461.
```

## 正文标注（人工保持）

圆括号内注明中国作者姓名或外国作者姓氏，多名作者加“等”或“et al.”，再注明出版年。多篇文献以分号隔开；相同第1作者的后续条目可只写年份；同年作品用 a、b 等区分。

例如：`（郭宝林等，2000；唐守正，1990）`、`(Biemont et al., 2009; Farrell, 2009)`。

Word 保留输入中的这些文字；对应关系和年份后缀需人工维护。需要自动管理时，仅 LaTeX 后端支持显式 BibTeX 输入，见 `zafu_latex_adapter.md`。
