# Formatting-first 执行架构

## 三条路线

`thesis_format.py` 增加 `--quality final|fast`、`--conservative`、`--render-backend` 和专家 `--pipeline legacy`，保留 `--mode`、`--check` 含义。显式 check 覆盖 quality。

普通请求由 `formatter_core/production.py` 执行：

- **Fast Build**：Markdown/TXT → 一次 evidence/ThesisIR → 既有 Word 构建器 → 确定性模板组合/样式落地 → 最终校验。取消编号、预检、inspect、策略选择和 planner 子进程。当前仍保留一个临时 markdown_source.docx，复用成熟的关系感知模板组合器；尚未做到内存中的单次 ZIP 写入。
- **Smart Normalize**：DOCX 轻量语义解析，不展开逐 run 有效字体审计；批量应用样式、三线表及内联图片尺寸规则，再执行最终内容、关系和格式验证。保留文字、强调、上下标、编号及原生包资源，不重建全文。
- **Conservative Repair**：安全区域照常规范化；批注范围（包含中间段落）、修订、浮动对象、原生公式、嵌入对象、内容控件及分节载体按顶层段落/表格保护。复杂多节文档保留分节几何。受保护区域引用的样式及祖先样式不改，必要时给可编辑区域建立独立目标样式。

复杂区域目前按整个顶层对象保护，不能可靠重建浮动布局、修订、OLE、复杂公式、合并表格和复杂分节。报告给出 bodyChildIndex、类型及原因；保留不代表已经符合格式规范。不会因为局部公式而停止全篇普通正文排版。

`--conservative` 或 `--mode conservative-repair` 显式要求保守处理。`--mode audit-only` 保留旧审计链；`--allow-structural-rebuild` 明确授权后保留旧模板重建能力。`--pipeline legacy` 供旧报告消费者及旧式文本公式转换、参考文献拆分使用，普通排版不需要。

## 解析与缓存

`formatter_core/session.py` 提供执行作用域内的内容哈希缓存，返回独立副本，避免 planner 修改共享验证数据。模板分析跨相邻运行复用，缓存位于 `<输出基目录>/<项目>/.template-cache/`；键包括模板、规则内容及实现文件哈希。规则复制到新运行目录不导致失效，内容或实现变化则失效。源 DOCX 的轻量视图和最终完整格式视图不混用。

串行 CLI 改为模块 main 的进程内适配，各模块独立 CLI 仍可使用。普通路线 evidence/IR 经函数传递，仅保留 IR、计划、执行记录与最终校验等有复查价值的 JSON；旧报告链保留全部诊断契约。

## 最小充分校验

安全规范化比对全文文字序列、公式文本、媒体/嵌入文件/脚注/尾注/批注哈希，以及表格、公式、修订等对象数量。检查全部包关系目标。文字源输出检查构建前各段文字仍可在成品找到（允许已有参考文献去数字标签规则）、公式文本和资产保留。后者不是通用语义证明。既有包结构、域、字体、标题、页眉页脚、图表和参考文献验证继续执行。

硬失败保留工作目录候选，不发布 DOCX/PDF；原稿不覆盖。未执行的渲染不标通过。技术日志不是学校 AI 使用披露，工具不伪造声明。

## 视觉与停止条件

转换一次 PDF，先做程序文本/几何/结构检测，再选择高清页，连续页范围合并渲染；全文使用低清总览。PDF 缓存绑定候选哈希、后端和转换实现；预览绑定 PDF 哈希、分析实现和检查级别。候选修改后使用新目录。

唯一文本锚点连接 Word 与 ThesisIR；重复文本报告歧义。优先使用 Poppler 测得的文字框；降级到近似基线时不执行依赖准确坐标的判断。不承诺任意文字重叠、截断、图片比例或复杂图表归属识别。跨页表格仅在多个唯一单元格锚点支持时提示缺少重复表头。不能确认的题注不猜测上一段。

计划去重、隔离冲突、排序，修复后复验；新证据支持的可靠定位问题继续处理，连续两次同类尝试无改善则停止该方法并列出剩余问题。新增完整性硬失败恢复最近通过版本。真实看图和证据记录见 [视觉验收](optional_visual_review.md)。

内部状态只用于追溯；对用户的完成承诺以成品满足要求为准。普通路线生成前后缺项清单，缺失正文/摘要页眉默认补齐，参考文献识别失败不能静默通过。缺失前置页需由 Agent 按 SKILL.md 的模板组合步骤补齐，默认保守 CLI 本身不插入封面。实测数据、现存失败及验证范围见 [性能与回归](performance_baseline.md)。
